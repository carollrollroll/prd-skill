# prd-skill

## PRD Skills 自動載入

PRD skill 定義位於 `../skills/`，每個子目錄下各有一個 `SKILL.md`。

進行任何 PRD 撰寫或審查任務前，掃描並載入該目錄下所有 `*/SKILL.md`，使對應 skill 在本 session 生效。

| Skill | 路徑 | 說明 |
|-------|------|------|
| `/prd-write` | `../skills/prd-write/SKILL.md` | 撰寫 PRD（Full / Lite）|
| `/prd-review` | `../skills/prd-review/SKILL.md` | 審查 PRD 完整度 |
